# QuizRead（問読みスタジオ）

早押しクイズの問題文を、人の問読みに近い抑揚で、読み間違いなく読み上げるアプリです。クイズ研究会の例会で、複数人の早押し対戦に使えます。

## できること

- **読みを確定してから読み上げ**：読み辞書（kuromoji）で全語にふりがなを付け、その読みどおりに音声合成へ渡します。数と助数詞（300本→さんびゃっぽん、1月1日→いちがつついたち など）や「何でしょう」の「なん」はルールで判定します。読みが複数ある語は色で知らせ、クリックで直せます。
- **問読みらしい抑揚**：最初に「問題」とコール、「〜ですが、」で間を置いて後半へ、文末の「？」は下げ調子で言い切り。
- **早押し対戦**：キーボード（1人1キー／キーボードとして動く早押し機）、タブレットのタップ、スマホを早押しボタンにする方式に対応。7○3×・5○2×・ポイント制などの形式、誤答後に続きから読む、解答時間、判定の取り消し、記録のコピー。
- **3899問を収録**（12ジャンル）。問題はテキストや JSON で追加・書き出しできます。
- **難易度と出題範囲モード**：問題ごとに C・B・A・S の難易度（みんはやの難易度感を参考）が付いています。「問題集」タブの出題範囲で、次の4つのモードを選べます。

  | モード | 出題する難易度 |
  |---|---|
  | Cモード | C |
  | Bモード | C・B |
  | Aモード | B・A |
  | Sモード | A・S |

## 使い方

GitHub Pages で公開するか、ローカルでは次のコマンドで簡易サーバーを起動して `http://localhost:8000` を開きます。

```sh
npm run serve
```

ブラウザの制約により、`index.html` を `file://` で直接開く方法には対応していません。声は **Microsoft Edge の Natural 音声（Nanami など）** が最も自然です。Chrome なら「Google 日本語」を選んでください。

| キー | 操作 |
|---|---|
| Space | 読み上げ開始 ／ 次の問題へ |
| O ・ Enter | 正解 |
| X | 誤答 |
| T | スルー（答えを出す） |
| R | 最初から読む |
| U | 直前の判定を取り消す |
| ← → | 前・次の問題 |

### スマホを早押しボタンにする

司会が「参加者」タブの「受付を始める」を押すと、4桁のコードと QR コードが出ます。部員はスマホで QR を読み取るか、ページ右上の「スマホを早押しボタンにする」からコードを入力します。通信は WebRTC（PeerJS）で端末どうしを直接つなぎます。接続の仲介には PeerJS の公開サーバー（0.peerjs.com）を使います。通信の遅れで端末間に 0.1 秒ほどの差が出ることがあるため、僅差を争う対戦ではキーボードか早押し機をおすすめします。

## 問題の JSON 形式

「問題集」→「まとめて読み込む / 書き出す」で、貼り付けかファイルから **追加** できます（同じ問題文と答えの組はとばします）。

```json
[
  {"q": "日本で一番長い川は何でしょう？", "a": "信濃川", "g": "地理", "d": "C"},
  {"q": "「罪と罰《ばつ》」を書いたロシアの作家は誰でしょう？", "a": "ドストエフスキー", "g": "文学"}
]
```

書き出したファイルの形式 `{"questions": [...], "dict": {"表記": "よみ"}}` もそのまま読み込めます。`d` は難易度（`C` `B` `A` `S` のいずれか、省略可）です。`question` / `answer` / `genre` / `difficulty` のキー名にも対応しています。読みの指定は問題文の中に `漢字《よみ》`、区切りたいときは `｜語句《よみ》` と書きます。

テキストで追加する場合は1行1問で、`問題文<TAB>答え<TAB>ジャンル<TAB>難易度` か `問題文【答】答え` の形にします。

## ファイル構成

- `index.html` … 画面のHTML
- `assets/css/app.css` … 見た目とレイアウト
- `assets/js/app.js` … 読み上げ・対戦・編集などのアプリ処理
- `data/questions.json` … 初期収録問題（編集対象のデータ）
- `dict/` … 読み辞書（kuromoji の IPADIC 辞書）
- `vendor/` … kuromoji、QRコード、PeerJSなどの外部ライブラリ
- `scripts/validate-questions.mjs` … 問題データの検証

データ（問題・辞書・設定・得点）はブラウザの localStorage に保存されます。別の端末へ移すときは「JSON ファイルで保存」→「ファイルから追加」を使ってください。

### 収録問題を編集する

`data/questions.json` の各項目を編集します。キーは `id`（固定ID）、`genre`（ジャンル）、`difficulty`（難易度）、`question`（問題文）、`answer`（答え）です。難易度は `C` `B` `A` `S` のいずれかにします。保存済みの結果や読み修正との対応に使うため、既存問題の `id` は変更せず、新しい問題には重複しないIDを付けてください。

編集後は次のコマンドで、必須項目・難易度・重複を確認できます。

```sh
npm run check
```
